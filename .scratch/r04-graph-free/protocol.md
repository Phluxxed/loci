Frozen before the first scored execution. User outcome is architectural comparison and recommendation, not V2 or integration. All execution checkouts/stores are owned and disposable via benchmarks.architecture.

Architectures: original graph implementation at 4cadfe1 (R0.3 unchanged control, code-equivalent to the historical architectural harness control), graph-enabled R0.3 b75fe58, graph-free candidate at the commit containing this protocol. Both graph arms retain enrichment on. Two repetitions alternate arm order. Run original/R0.3 and R0.3/graph-free pairs, using identical source-acquisition rules. Retain historical results and their invalid proof status.

Existing harness operation `acquisition`: same authored entry query, at most five retrievals, sixteen continuation pages, soft admission limits 128 KiB source and 256 KiB output, charged full final response with overshoot. Hydrate incomplete source in returned order. Scheduler inputs contain only already delivered source and filename/hash/size inventory. Priority is first incompletely delivered file, inventory paths mentioned lexically (name/stem), ancestor manifests (fixed go.mod/go.work/Cargo.toml/jsconfig.json/tsconfig.json/package.json list), then source identifiers in observed order after a fixed keyword stoplist. Exact source bytes of scheduler are committed. No gold/relationships/scorer inputs reach it. No tuning based on scored misses. This policy's bounded failures are not impossibility claims about all graph-free retrieval.

Inventory projection is an explicit benchmark acquisition adapter for all arms. Graph arms project indexed source/control paths from file hashes/input hashes; candidate exposes its file-only inventory. Metadata projection/serialization is measured. Discovery JSON bytes are charged per independent case in delivered context. Inventory is not a claim that an unchanged normal graph MCP tool exposes a directory listing.

Keep initial and final frozen-span coverage, anchor-span coverage independent of graph IDs, unique/repeated source, complete envelope bytes, inventory bytes, fraction of snapshot delivered, indexing/storage/process CPU/RSS, retrieval/followup/continuation phases. Full cost includes snapshot indexes once per suite (shared Anvil snapshot indexed once for its three cases), current-source refresh work inside operations, child CPU, setup/import/archival. Phase RSS is cumulative process high-water mark; no claim of cold OS caches or statistical significance. Two fresh executions are descriptive.

Preserve the existing strict scorer and original packet-linked proof score. Audit finds five edges whose required caller definitions were actually delivered by continuations but not linked by original relation source IDs. Add a distinct aggregate-session proof metric: remap only independently byte/hash-validated same-case delivered sources, retain every original edge, run unchanged strict semantic scorers requiring the complete persisted support/control intervals. Never fetch additional source during scoring. Preserve packet failures; session success is not proof that normal packet links are complete. Graph-free has zero semantic claims and receives zero semantic proof credit. Negative controls remove every source's coverage of each caller's final byte; each affected proof must fail. Corrupt source must fail. Passing source acquisition is never task-answer correctness.

Acceptance: candidate safety checks and directly relevant existing harness regressions pass; all 36 cases attempted in each arm, resource failures retained, artifacts hash-bound and independently replayed. Source and proof deficits are valid findings, not reasons to optimize candidate or broaden experiment. Report native-agent questions and whether demand-driven semantic analysis deserves a separate next experiment. Stop after report; no production edits/integration or paid models.
