# R1 completed native pilot: recommendation to revise and hold advancement

The availability-qualified 16-assignment Terra 6.1/max pilot is complete. Native Codex and integrated Loci each pass three of four frozen graders; path-only passes two and eager passes one. **No scored session invokes Loci.** Optional semantics and focused proof therefore have no measured task benefit in this pilot. Tool exposure/callability is qualified; voluntary adoption was not observed. This supports holding advancement and revising the agent-facing workflow/evaluation interpretation, not rejecting the underlying semantic or proof algorithms. No production integration or additional pilot was performed.

All 16 archived grades and native traces independently replay without disagreement. Model/effort, native protections, task sources, oracle bytes, original scientific schedule and full catalogs were verified. The four separate operational probes positively exercised enabled operations, including integrated semantic analysis and proof following delivered identities. Each measured session performs the frozen first-action catalog query: native exposes zero Loci operations, path-only/eager two, integrated four. Those checks were counted as acquisition overhead; task use remained voluntary. Operational probes do not prove a successful tool invocation in every scored source copy.

## What the failed grades mean

The frozen graders are unchanged. An independent reviewer received 16 randomly ordered source/prompt/answer/oracle packets without condition labels, telemetry, trace or key access. Its diagnostics do not replace the official scores or create another aggregate score.

- Receipt location: all answers identify the supported active receipt owner/key; three fail strict equality because their chain representation differs. The prompt requests exact top-level fields but does not fully specify nested serialization. The reviewer also notes that answers do not explicitly explain the similarly named helpers, and that a linear chain can obscure sibling calls. These are retained answer/prompt qualifications, not a declaration that every answer fully satisfies every textual request.
- Inventory contract: eager supplies correct source paths with symbol objects instead of the expected path strings and fails equality. Passing answers use path strings but omit symbol citations within that field, despite the general preamble asking for symbols. The source/runtime contract is supported; the serializer partly determines frozen correctness.
- Dispatch ambiguity: all four pass, and source review supports registry-dependent selection, registered handlers, unknown-kind rejection and a separate legacy path. No semantic tool was consulted.
- Zero quantity: all four implementations pass the task runtime checks. Native, path-only and eager additionally create test/quantity.test.js and fail the wrapper’s file allowlist. That restriction is in the frozen criteria but not explicitly in the visible prompt, which asks for a relevant check. Integrated stays inside the allowlist. Its official advantage on this task cannot demonstrate semantic assistance.

Across the 12 Loci-enabled sessions, there are zero retrieval/read calls, zero semantic requests and zero focused proof requests; native captures contain no Loci MCP events or direct Loci operation invocations. Tool-name exposure is therefore distinct from tool adoption. The agent uses native shell/file tools to inspect the small independent JS problems. Loci-delivered source/proof bytes are zero; unique native source bytes, exhaustive repeated reads and acquisition-only elapsed time remain unknown. Full raw calls and a shell command index are retained rather than imputed. There are 15 failed shell attempts, no failed non-shell native items, no delegated task work and no context compactions. A shell exit such as a search with no matches is counted as observed, without assuming it caused a task error.

No task-level request tested how optional semantics handles uncertainty, whether proof fills a missing evidence gap, or whether a relationship would be promoted unsupported. The combined deterministic qualification and separate probe evidence retain their narrower role: the implementation’s support/invalidation/proof contracts, not agent utility. Python/Go semantics remain unsupported. This pilot covers four small independently constructed JS problems, not maintained-repository breadth.

## Protocol and remaining limits

The first native task was preserved and recovered under the explicitly authorized personal-host observation amendment. Its raw trace retains one mid-turn agents_md instruction replacement; the source/task/grader/model/effort/tools/protections did not change. Unused agent-profile settings and global personal instructions are observed covariates, so instruction exposure was not fixed across the entire pilot. Hooks, project instructions, Loci skill and candidate code remain pinned. This narrows comparative claims. The four-task count and this deviation do not permit a statistically reliable superiority claim. Earlier Sol and availability-unverified Terra attempts remain separate and are not pooled.

The unattended dispatcher is implemented in the existing runner, but the current agent host’s actual launchd submission failed and no job registered. The pilot was completed by the authorized external Terminal route. Autonomous top-level execution from this managed session remains a genuine platform blocker, separate from the now-completed pilot and recovered accounting. No new sandbox, permission profile, global setting, launcher framework or production integration was added.

## Recommendation

**Revise / hold advancement.** The integrated implementation remains an operational experimental candidate with deterministic qualification and independently replayable native evidence. This pilot establishes an adoption failure under voluntary task use despite verified discovery/callability. It supplies no evidence that semantic analysis or focused proof improves task success, time or tokens. The frozen-score contrasts are materially influenced by representation and undisclosed file-allowlist policy. Do not advance on the 3/4 score, declare eager inferior, or reject the semantic/proof design from zero use. Any later workflow or rubric revision should be prospectively declared; no such tuning or additional experiment was performed here.
