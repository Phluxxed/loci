## Question and necessary scope

Does explicit exploration routing satisfy the existing delivery requirements
when both conditions use the repaired tool contract and observer?

The routing-v1 comparison retains its numerical **keep** and strict qualification
**inconclusive** at `633ca52c528b51741f6e8e0fc0aa18c7ee21af81`. Six of nine
initial maintained B calls failed null byte-limit validation; later recovery did
not satisfy initial exposure. Argument and observation repairs are published at
`c14b2a87a8dde6543c7c790888619bad94711430` with 77 focused tests and 11 offline
Codex/MCP modes. Those scripted checks establish repair behavior, not provider
adoption or comparative delivery performance.

Qualification will use **102 fresh matched attempts: 17 cases × 3 repetitions ×
2 conditions**. This is an explicit scope decision, not an automatic repeat
because graph children were added. The unchanged evaluator requires 51 complete
measurements per arm, 42 candidate fixture passes, and no per-task success
regression across all 17 cases. Nine B maintained attempts could establish
initial source exposure only. Eighteen matched maintained attempts could also
measure maintained costs and recall, but neither supplies the fixture and full
batch gates. Combining those new outcomes with old-schema measurements would
mix effective contracts. Earlier results remain historical context only.

## Acceptance and evidence

All fourteen numerical gates use the unchanged frozen evaluator. Qualification
also requires all nine B maintained attempts to begin repository retrieval with
`loci_explore(intent="type_dependencies")` and receive the requested source
anchor. Source must match the pinned declaration, file hash and trace span.
Clipped receipt is reported separately from complete coverage; source-recall
gates still apply. Later recovery never replaces a failed first exposure.

Every attempt, failure, helper call, retry made by the model within an attempt,
and fallback cost is retained. Provider input includes the policy and cached
input; cached input is reported separately. No selective attempt retries,
replacement, dropped runs, changed thresholds or post-outcome repair is allowed.
An interrupted attempt remains evidence and cannot be overwritten. Resume may
continue only untouched scheduled attempts after validating the unchanged freeze.

Independent replay must verify all 102 attempts, exact source/relationships,
native payloads, request and A/B identities, observed routing, measurements and
costs before reporting qualification. A complete comparison with numeric or
known exposure failure is rejected. Missing measurements, unknown routing or
incomplete replay is inconclusive. Publish every gate and limitation either way.

This campaign can close delivery acceptance only if all existing requirements
pass. It does not promote the shared runtime or complete multilingual W4. A
failed qualification does not authorize an automatic follow-up experiment.
