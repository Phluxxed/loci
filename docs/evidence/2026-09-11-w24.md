## Result

`loci_explore` selects source for `locate`, `type_dependencies` or `impact`.
It reuses indexed anchor selection, proven graph records and cached source.
Type selection prioritizes direct contracts and structural continuation, then
uses query terms to choose deeper fields. Static impact follows incoming edges
and preserves their original direction. Resolution filters admit only exact or
import-resolved relationships. Selection heuristics never create graph facts.

Each delivered item links to source and its original proof path. Related
source and missing proof fit atomically; oversized items can be skipped in favor
of later smaller items. Anchors can return an explicit UTF-8-safe prefix.
Independent source and complete MCP-result byte limits account for definitions,
support, metadata, omissions and framing. Reported token counts are labelled
byte heuristics. Relationship scope is non-exhaustive and omitted uncertainty
remains visible. The [design contract](../design/2026-09-11-intent-evidence.md)
defines the interface and its bounds.
